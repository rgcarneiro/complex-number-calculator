# Complex Number Calculator

A command-line calculator for performing operations with complex numbers.  
This project allows users to execute basic arithmetic and conjugation operations interactively, using Python’s built-in complex type along with NumPy for handling conjugates.

## Description

The calculator provides an intuitive text-based interface for working with complex numbers.  
Users can enter the real and imaginary parts manually or use constants such as **pi** and **euler** for more advanced computations.

Supported operations include:
- Conjugation
- Addition
- Subtraction
- Multiplication
- Division

It also allows the user to reuse the result of a previous operation or restart the calculator at any time.

## Features

- Interactive command-line input for complex numbers  
- Arithmetic operations between two complex numbers  
- Automatic result chaining for continued calculations  
- Support for special constants `pi` and `euler`  
- Option to exit or restart from any point
